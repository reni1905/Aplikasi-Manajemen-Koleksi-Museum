# Aplikasi-Manajemen-Koleksi-Museum
## Web-Based Museum Collection Management Application for the Cirebon Regency Culture and Tourism Office - As a developer.
## Problems : The cataloging and management of the Pangeran Cakrabuwana Museum's collection are still carried out manually using logbooks or spreadsheets (Microsoft Excel); this makes it difficult for administrators to record, update, and retrieve data, and hinders the department head from quickly obtaining reports on the collection.
## Solutions: Developing a web-based application using the Laravel framework that includes CRUD (Create, Read, Update, Delete) functionality for administrators to manage collection data, as well as a feature for the department head to download reports in PDF format.
# Tech Stack: PHP, MySQL, Laravel, Bootstrap, Visual Studio Code, XAMPP.
# Result: It assists administrators in managing museum collection data in a structured and integrated manner, and enables the department head to quickly and accurately download collection data reports in PDF format.
## Notes: The collection data count feature on the dashboard page is not yet functional. The dashboard page lacks sufficient detail. The CRUD table display does not fit the screen properly, requiring scrolling to view other data. There is no image column in the CRUD data table.
